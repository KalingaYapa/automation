# Repository instructions

When adding an automation test case, update `docs/test-case-catalog.md` in the same change. Include its test case ID, name, automation method, objective and expected result. Keep the catalog aligned when a case is renamed, changed, disabled or removed. Distinguish sample-template cases from application cases when IDs overlap.

When writing new automation tests, follow `docs/test-writing-guide.md` for the team test/Page Object structure, step logging, frame handling and code-quality checks. Use the existing repository setup and groups as explained in that guide; do not duplicate login or silently change suite conventions.
